# Release signing (public)

This project ships a **public** release keystore for CI and local release builds.
Do **not** use it for Play Store / 应用商店 apps that need private signing.

| Field | Value |
|-------|-------|
| File | `billremind-release.jks` |
| Store password | `billremind123` |
| Key alias | `billremind` |
| Key password | `billremind123` |
| Validity | 10000 days |
